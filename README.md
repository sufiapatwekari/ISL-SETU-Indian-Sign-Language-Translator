# ISL Setu — Indian Sign Language Translator

ISL Setu is a two-way Indian Sign Language (ISL) communication system that enables real-time conversations between deaf and hard-of-hearing individuals and hearing people.

The system aims to make communication easier and more accessible through sign language recognition, text-to-speech conversion, and animated sign language representation.

## Features

### 1. Sign → Text → Speech
- Recognizes Indian Sign Language gestures using a webcam.
- Converts recognized signs into gloss.
- Translates gloss into natural sentences in English, Hindi, and Marathi.
- Converts translated sentences into speech.

### 2. Text → Sign
- Converts typed sentences into ISL gloss.
- Displays corresponding signs through a hand-skeleton avatar on canvas.

### 3. Role-Based Usage

Provides separate workflows for:
- Doctor
- Police
- Teacher
- Public

Includes operator login, deaf and hard-of-hearing person details, and a conversation history dashboard using Spring Boot and MySQL.
